# Design Principles

The homepage should feel:

- Editorial
- Research-oriented
- Documentary
- Human
- Calm
- Modern
- Credible

Avoid:

- Generic portfolio layouts
- SaaS-style dashboards
- Excessive gradients
- Excessive animations
- 3D effects
- Unnecessary cards
- Visual clutter
- Overly corporate language

---

# Component Strategy

Do not create every component upfront.

Build progressively:

Phase 1:
- SiteHeader
- Hero
- Basic Footer

Phase 2:
- Introduction
- CoreAreas
- SelectedWork

Phase 3:
- ResearchPreview
- WritingPreview
- FieldworkPreview

Phase 4:
- Academic
- Now
- ClosingCTA

Only create reusable components when actual repetition appears.
