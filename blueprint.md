## Design Direction

Editorial + Research + Documentary

The design should feel:

- Clean
- Serious
- Human
- Modern
- Content-focused
- Culturally grounded

Avoid:

- Excessive animations
- Unnecessary 3D effects
- Visual clutter
- Over-engineering

---

## Technical Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui

---

## Architecture Principles

1. Keep the initial architecture simple.
2. Avoid premature abstraction.
3. Build components when they are actually needed.
4. Prefer reusable UI primitives.
5. Keep content independent from presentation.
6. Optimize for accessibility and performance.
7. Keep the project maintainable for long-term development.
8. Prefer open-source and portable solutions.
